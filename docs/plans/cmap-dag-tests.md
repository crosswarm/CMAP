# DAG test specification

Contract: positive fork/join; reject duplicate IDs/criteria, self/missing/cyclic deps (including disconnected cycle), empty graph, unsupported fields, excessive bounds, missing/duplicate Mission criterion coverage, changed request-key plan. No Store write/start before validation.
Materialization: repeat call creates one Task/event; simulate partial failure and retry; node acceptance/risk/routing preserved across successor; child deps reference accepted final attempt; namespaces avoid same-name upstream artifact collision; hash mismatch/symlink escape/missing artifact blocks copy; child modifications leave original unchanged. Same suite where applicable on Memory/PG.
Workflow: two ready nodes overlap but never exceed concurrency; join starts after both accepted; forced rework picks final parent; one failed/ESCALATED branch blocks join and prevents Mission COMPLETED; remaining started branches settle. Individual approvals stay separate and no premature dispatch; lock contention serializes identical resource, lease loss terminates owning attempt, finally releases. Retry/replay does not duplicate tasks/side effects. Nonretryable adapter failures persist truthful failed results.
Compatibility: all inspect success, rework and approval tests remain green; replay stored real histories (without saving raw payloads); no nondeterministic Workflow APIs.
API/UI: old create/retry/start behavior unchanged; plan mismatch409; correct stored Workflow template on DRAFT resume. Planned nodes with no Task still visible; blocked and reworked lineage accurate; no provider identity or raw logs shown.
Actual e2e: dedicated schema/queue/workroot; two independent branches on real Codex and Kimi produce known numeric artifacts, final node reads copied evidence and reports independently recomputed total. Verify chosen adapters, timestamps/order, actual files/hashes, Task/Mission states and Temporal replay. Observe with current UI or dedicated API. Synthetic failures are labeled; no production data.
Checks: schema→codegen→meaningful red test→minimal implementation; npm run check; npm run test:pg; build:web if UI changed; focused real e2e, replay, diff/links/hooks. Record validation gaps and do not mark the complete project done at this milestone.

Architect v2 additions: a predecessor marked COMPLETED due to rework but lacking an accept Review must NOT unblock children. Concurrent identical Task/Review creation must converge in both stores; conflicting immutable input must fail without resetting prior state or adding events. Reject multi-followup node review before any successor write. Lock acquisition must not cause RUNNING→QUEUED; lease loss cancellation must be observed before claiming stop/release. Node-aware acceptance projection must distinguish different nodes' results rather than using the globally newest task. Rework increments Task attempt and envelope revision together. finalizeDagMission rereads ledger truth and rejects incomplete coverage or a claimed accepted outcome without an accept Review.

Architect v3: reject plan node risk above Mission ceiling before any Store write; mutating ceiling plus controlled node still requires independent controlled approval. Simulate cancel never becoming terminal within 5 seconds: result escalated/CANCELLATION_UNCONFIRMED, renewals stop, owned leases are not voluntarily released, and no claim of stopped execution is recorded.
